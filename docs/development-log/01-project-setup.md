# Initial Spring Boot Setup

**Date:** 2026-09-02
**Project:** PayRoute
## Objective
Initialize the PayRoute backend project using Spring Initializr and
prepare the basic Spring Boot development environment.

## Project Initialization
The project was created using **Spring Initializr** with the following
configuration:

- **Project:** Maven
- **Language:** Java
- **Packaging:** JAR
- **Java:** 25
- **Spring Boot:** 4.0.8
- **Configuration:** YAML

## Dependencies

The following dependencies were selected during project initialization:

- **Spring Web** — for building RESTful web APIs
- **Spring Data JPA** — for database persistence and ORM
- **PostgreSQL Driver** — for connecting the application to PostgreSQL
- **Lombok** — for reducing boilerplate code such as getters, setters,
  constructors, and other common methods
